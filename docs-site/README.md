# docs-site

Source for [docs.fixyourdocs.io](https://docs.fixyourdocs.io) — the
canonical, versioned documentation for the **FixYourDocs product** (the
protocol, both SDKs, the CLI, the AGENTS.md snippet, the Hub, and the MCP
server). Built with [Starlight](https://starlight.astro.build).

Distinct from [docsfeedback.org](https://docsfeedback.org), which is the home
of the *protocol* itself. This site documents the product and links out to
the spec rather than duplicating it.

## Commands

Run from the monorepo root:

| Command | What it does |
| --- | --- |
| `pnpm --filter @fyd/docs-site dev` | Starlight dev server at `http://localhost:4321` |
| `pnpm --filter @fyd/docs-site sync` | Regenerate `.well-known` + AGENTS.md and sync snippets from sibling repos |
| `pnpm --filter @fyd/docs-site build` | Production build to `dist/` (runs `sync` first via `prebuild`) |
| `pnpm --filter @fyd/docs-site preview` | Preview the production build locally |

## Versioning

Content-folder versioning, git-tag cut:

- The current docs are authored under `src/content/docs/v0/` and served at
  `/v0/`. Bare paths (`/getting-started`, …) redirect to the current version.
- A release cut tags `main` (`docs-v0.1`) and **copies** `v0/` → `v0.1/`, so
  `/v0.1/` is frozen while `/v0/` keeps moving. See the
  [Versioning page](src/content/docs/v0/versioning.mdx) for the reader-facing
  contract.

## Dogfooding

This site is itself a Docs Feedback Protocol target:

- `public/.well-known/docs-feedback.json` — discovery doc (`opt_in: true`,
  `endpoint: https://hub.fixyourdocs.io/v1/reports`). Generated by
  `scripts/well-known.mjs`.
- `public/AGENTS.md` — the canonical AGENTS.md block, served verbatim at
  `/AGENTS.md`. Synced from `../../agents-md-snippet/` by
  `scripts/sync-snippets.mjs`.
- A "File a docs-feedback report" link in every page footer
  (`src/components/Footer.astro`) → the on-site form
  (`src/components/ReportForm.astro`).

Closing the loop (reports → GitHub Issues) requires a one-time Hub-side
verified-domain setup for `docs.fixyourdocs.io` — see the
[Hub guide](src/content/docs/v0/hub.mdx).

## Snippet sync

`scripts/sync-snippets.mjs` copies fenced regions marked with
`>>> doc-snippet <name>` / `<<< doc-snippet` from sibling checkouts
(`../../sdk-python/`, `../../sdk-typescript/`, `../../agents-md-snippet/`,
`../../protocol/`) into `src/content/docs/v0/_snippets/`. It no-ops with a
warning when a sibling isn't checked out or a file has no markers, so CI
builds from the committed copies.
